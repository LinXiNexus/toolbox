# 常用工具集 (模块化版)

身份证 / 手机号 相关的小工具集合，交互式菜单驱动。

## 运行

```bash
cd toolbox
python3 main.py
```

## 目录结构

```
toolbox/
├── main.py        主控：主菜单 + 模块分发
├── common.py      通用：终端着色、输入(含 exit 返回)、列表展示
├── lunar.py       农历年表 + 生肖 / 星座 / 年龄计算
├── idbase.py      身份证底层：常量、校验算法、地区码表
├── idcard.py      身份证交互：菜单 + 6 个功能
├── phonedb.py     手机号号段库：phone.dat 解析与查询
├── phone.py       手机号交互：菜单 + 5 个功能
├── data/
│   ├── regions.txt      行政区划码表 (2978 条, 6 位区县级)
│   └── phone.dat        手机号段库 (499527 条)
├── ids_sample.txt       示例：身份证号文件
└── README.md
```

## 模块依赖

```
main.py ──> idcard.py ──> idbase.py ──> (data/regions.txt)
   │            └──────> lunar.py
   └──────> phone.py ──> phonedb.py ──> (data/phone.dat)
common.py  <── 所有模块共用
```

## 功能一览

### 身份证菜单

| 编号 | 功能 | 说明 |
|---|---|---|
| 1 | 后四位穷举 | 已知前 14 位 + 性别，穷举后 4 位 (500 条) |
| 2 | 17位补校验位 | 输入前 17 位，算出第 18 位 |
| 3 | 校验18位号码 | 逐项校验省级码 / 地区码 / 出生日期 / 校验位 |
| 4 | 批量校验(从文件) | 从 txt 读号码批量校验，可导出 CSV |
| 5 | 信息提取 | 地区 / 生日 / 年龄 / 生肖 / 星座 / 性别 |
| 6 | 按生肖/星座反推号码 | 用生肖(农历) / 星座 / 年龄反推生日，再生成候选号码 |

### 手机号菜单

| 编号 | 功能 | 说明 |
|---|---|---|
| 1 | 查询归属地 | 输入号码，输出归属地 / 运营商 / 邮编 / 区号 |
| 2 | 前三后二穷举手机号 | 已知前三位 + 后两位，穷举中间 6 位 |
| 3 | 批量归属地查询(从文件) | 从 txt 读号码批量查询，可导出 CSV |
| 4 | 号段反查(按地区) | 输入地区关键字，列出该地区全部号段 |
| 5 | 格式化 / 脱敏 | 格式化 / 脱敏 / 清洗 / 加国际码 |

## 通用操作

- 任意输入处输入 `exit` (或 `back` / `返回`) 可返回上一层
- 分页预览时输入 `q` 直接回主菜单
- `Ctrl+C` 随时中断
- 结果超过 20000 条时自动改为流式写文件，不占内存

## 数据来源

- `regions.txt`：国家统计局行政区划代码 (6 位区县级)
- `phone.dat`：开源项目 ls0f/phone (MIT)，2023年12月版
- 农历数据：lunardate (GPLv2)，覆盖 1900-2099

## 注意

所有结果仅保证**格式与校验位合法**，不代表号码真实存在。
请仅用于本人证件或已获授权的合法用途。
